BAHLOU

1. Installe l'appli

Ubuntu, Debian

Après le téléchargement, lance depuis ton dossier de téléchargements :

sudo apt install ./bahlou.deb Télécharger

Arch

Après le téléchargement, lance depuis ton dossier de téléchargements :

sudo pacman -U bahlou.pacman Télécharger

Autre Linux

Un seul fichier, sans installation :

chmod +x Bahlou.AppImage && ./Bahlou.AppImage Télécharger

Sur Windows, Mac ou téléphone, ouvre Bahlou dans le navigateur : le Salon et les Jeux fonctionnent, mais la connexion à my.epitech demande l'appli.

2. Connecte l'appli

  1. Ouvre l'appli : elle se connecte toute seule.
  2. Choisis Inscription et crée ton compte.
  3. Colle le code d'invitation ci-dessous.
